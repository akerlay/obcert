# obcert

**Доверяй корневому сертификату Минцифры РФ только для нужных доменов.**

obcert — приложение для macOS. Оно позволяет открывать российские сайты, которые
отдают TLS-сертификаты Минцифры (Госуслуги, банки и т.п.), **не** давая при этом
государственному корневому сертификату возможность подписывать сертификаты для
всего остального интернета. Вы указываете список доменов — и сертификаты Минцифры
принимаются только для них и их поддоменов.

Целевая аудитория — обычные люди: скачал, перетащил в «Программы», вписал домены,
нажал «Применить».

---

## Как это работает

При полном доверии к корню Минцифры государство технически может выпустить
валидный сертификат для **любого** домена — то есть незаметно перехватывать (MITM)
любой HTTPS-трафик. obcert заменяет безусловное доверие на доверие с ограничением.

1. **Локальный ограниченный корень.** Приложение генерирует на вашем компьютере
   новый корневой центр сертификации (приватный ключ никуда не уходит) с
   критическим расширением `nameConstraints`, где в списке разрешённых —
   только ваши домены (и `excluded` для всех IP-адресов).

2. **Кросс-подпись корня Минцифры.** Приложение берёт настоящий корень Минцифры и
   выпускает его «двойника»: с тем же субъектом, тем же публичным ключом, тем же
   Subject Key Identifier и серийным номером — но подписанного **вашим** локальным
   корнем (эквивалент `openssl x509 -force_pubkey`). Настоящий безусловный корень
   Минцифры в хранилище доверия **не добавляется**.

3. **Цепочка достраивается через ограничение.** Реальный сертификат российского
   сайта строит путь `сайт → промежуточный Минцифры → двойник → ваш локальный
   корень`. Ваш корень доверенный, но его `nameConstraints` разрешают только
   перечисленные домены. Сертификат Минцифры для домена вне списка не проходит
   проверку.

Приложение устанавливает это в системное хранилище macOS (Keychain — Safari,
Chrome) и в хранилище NSS каждого профиля Firefox (через встроенный `certutil`).

### Важное условие: оригинал Минцифры не должен быть доверенным

Ограничение работает во всех браузерах **при условии**, что в системе не установлен
доверенным **оригинальный, неограниченный** корень Минцифры — иначе сертификат
Минцифры для любого домена пройдёт проверку напрямую по нему, в обход ограничения.

Поэтому при запуске obcert проверяет наличие оригинального корня Минцифры (по
закреплённому отпечатку SHA-256, что отличает его от нашего «двойника» с тем же
именем) и, если находит, **блокирует работу** до его удаления — с кнопкой удаления
в один клик (запросит пароль администратора).

## Возможности

- Список разрешённых доменов; каждый домен автоматически включает все поддомены
  (`sberbank.ru` покрывает `online.sberbank.ru` и т.д.). Поддерживаются зоны
  (`.ru`) и кириллица (`.рф` → Punycode).
- Готовые наборы: «Госуслуги», «Крупные банки», «Весь .ru / .рф / .su».
- Установка во все браузеры одним нажатием (один запрос пароля администратора).
- **Экспорт для телефона**: профиль `.mobileconfig` для iPhone/iPad и файлы
  `.pem`/`.crt` для Android.
- Кнопка полного удаления всего установленного.
- Блокировка при обнаружении оригинального корня Минцифры + его удаление.

## Установка сертификата на телефон

Кнопка «Экспорт для телефона…» сохраняет в выбранную папку:

- **`obcert.mobileconfig`** — профиль конфигурации для **iPhone/iPad**. Передайте
  его на устройство (AirDrop, почта), откройте, установите профиль
  (Настройки → Профиль загружен), затем включите полное доверие в
  Настройки → Основные → Об этом устройстве → Доверие сертификатам.
- **`obcert-root.pem`, `obcert-cross.pem`, `obcert-intermediate-*.pem`** — для
  **Android**: Настройки → Безопасность → Установить сертификат → Сертификат ЦС.

На телефоне действует то же условие: оригинальный корень Минцифры не должен быть
установлен доверенным.

## Безопасность

- Корневые сертификаты Минцифры скачиваются с официального источника
  (`gu-st.ru`, раздел gosuslugi), а отпечаток корня (SHA-256) **закреплён** в
  приложении — при несовпадении установка отменяется.
- Приватный ключ локального корня генерируется и хранится только на вашем
  компьютере (права `600`).
- Оригинальный неограниченный корень Минцифры блокирует работу приложения до
  удаления.

**Оговорка честности:** name constraints строго и давно соблюдаются в Firefox;
современные Safari и Chrome их также соблюдают. Ключевой риск обхода — наличие
доверенного оригинального корня Минцифры, и именно его obcert обнаруживает и
требует удалить.

## Сборка

Требуется macOS 13+, Xcode 15+.

```bash
# 1. Тесты ядра (библиотека CheburcertCore)
swift test

# 2. Инструменты сборки приложения
brew install nss xcodegen

# 3. Вложить self-contained certutil в приложение
./scripts/bundle-certutil.sh

# 4. Сгенерировать проект и собрать
cd App/CheburcertApp
xcodegen generate
xcodebuild -scheme obcert -configuration Release build
```

Готовый `.dmg` (с подписью и нотаризацией) собирается через `scripts/make-dmg.sh`
(нужны переменные окружения `DEVELOPER_ID_APP` и `NOTARY_PROFILE`).

## Ручная проверка (полный сценарий)

Проверять лучше на отдельной учётной записи macOS или в виртуальной машине — это
изменяет реальные хранилища доверия.

1. Соберите Release и запустите `obcert.app`.
2. Если открылся экран «Обнаружен оригинальный корень Минцифры» — удалите оригинал
   кнопкой (пароль администратора) и дождитесь основного экрана.
3. Добавьте `gosuslugi.ru`, нажмите **Применить**, введите пароль администратора.
4. В строке статуса появятся Safari · Chrome · Firefox с числом профилей.
5. В **Firefox** откройте реальный сайт с сертификатом Минцифры (гос./банковский
   `.ru`) — он открывается без предупреждения о сертификате.
6. Проверьте, что сертификат Минцифры для домена **не из** списка отклоняется с
   ошибкой ограничения имён (`SEC_ERROR_...`).
7. Нажмите **Удалить всё** — статус вернётся в «Защита выключена»; в Firefox
   (Настройки → Приватность и защита → Сертификаты → Просмотр → Центры
   сертификации) корень «obcert Local Constrained Root» исчезнет.

## Архитектура (для разработчиков)

- **`CheburcertCore`** — библиотека Swift Package (вся логика, покрыта тестами):
  нормализация доменов, крипто-движок (`nameConstraints` + кросс-подпись),
  скачивание и пиннинг сертификатов, установщики Keychain и Firefox, детектор
  оригинального корня, экспорт для телефона, оркестрация.
- **`App/CheburcertApp`** — тонкий SwiftUI-слой (одно окно) поверх библиотеки,
  плюс вложенный `certutil` для Firefox.
